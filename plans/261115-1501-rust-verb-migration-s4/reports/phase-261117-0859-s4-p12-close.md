## Lessons

- The fixed-then-widened door pattern and the "accepted difference" filters both hid a second effect: `next` dedupes by command, so a
  normaliser that removes one side's entry must keep it where another row names it. Pin the accepted difference per row and compare the
  rest as is.
- A linked worktree resolves its `fgctl` workspace to the main checkout, so it cannot stand in for "this repo" in a latency run; a
  `git clone --local` can, and the delete guard then refuses the cleanup. Plan the cleanup route (or reuse one clone) before creating
  throwaway checkouts.
- Run measurement fixtures through the real activated shim; the staged debug host and a hand-patched manifest cost an hour (artifact
  digest, addon path, writer identity all differ).
- The privacy hook reads `process.env` inside a heredoc as a file named `process.env`; write such scripts with the file tool.
- A bounded wait loop must match a pid, not a pattern: a `pgrep -f` loop matches itself.
