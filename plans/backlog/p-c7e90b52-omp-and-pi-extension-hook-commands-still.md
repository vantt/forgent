# Why

OMP and Pi extension hook commands still resolve from the session cwd. The codex and agy hook files were moved to an absolute shim path; a relative hook command run from a directory without `.fgos/installation` exits 127 and the worker's tools are blocked. Open it when an OMP or Pi worker is seen blocked by a failing hook, or when those hook files are next generated by `fgos setup`.

# Done when

OMP and Pi hook commands are written with the absolute shim path like the codex and agy ones, and a test runs the hook from an unrelated cwd without exit 127
