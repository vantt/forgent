# Why

The only shared rule is the five-part decision question (`core/skills/_shared/decision-question.md`), and it covers questions only. On 2026-11-22 the owner met seven avoidable frictions: agents asking permission to do read-only work, status reports resting on a liveness flag, stale owner questions (5 of 8 were moot), unexplained roles and ids, answer friction, no shared shape for progress reports, and a lesson stored in one head's private memory. Evidence and detail: `plans/reports/secretary-261122-1254-agent-human-communication.md`.

# Done when

One shared source, loaded by every head, lead and worker, defines how an agent communicates with the owner: questions, status reports and incident reports. It states what is done first and what is asked, how a recommendation and a default are shown, how names and ids are introduced, how a stale question is withdrawn, and which rules `fgos questions ask` checks by program. Existing heads and skills point to it, and the old scattered text is removed in the same change.
