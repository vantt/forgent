## Requirements

1. Mọi file `.md` mà `assembleSkills` ghi vào `.agents/skills/**` mang một dòng header generated, đặt **sau** frontmatter nếu file có frontmatter, ở dòng 1 nếu không. Header nêu đường dẫn source tương đối repo (`core/skills/<name>/...`, `core/skills/_shared/...` hoặc `domains/<d>/skills/...`) và lệnh `npm run build:skills` (ghi rõ là lệnh của repo nguồn fgOS, để đúng cả khi bản copy nằm trong project ngoài).
2. Dạng header: một HTML comment một dòng, ví dụ `<!-- Generated by fgOS skill assembly from core/skills/fgos-routing/SKILL.md (npm run build:skills in the fgOS source repo). Do not edit this copy; it is overwritten. -->`. Agent đọc raw thấy; markdown render ẩn.
3. Frontmatter giữ nguyên byte: `extractFrontmatter(output) === extractFrontmatter(source)`.
4. Plugin mirror (`plugins/fgOS/skills/{fgos-*,_shared}`) và file phụ của wrapper `.claude/skills/fgos-*/**` nhận header vì chúng copy từ `.agents` — không cần code riêng.
5. Wrapper `.claude/skills/*/SKILL.md`: giữ nguyên dòng `GENERATED_WRAPPER_MARKER`; **sửa** câu "this project's own canonical skill source" thành câu nói đúng: file được trỏ là bản assembled, header của nó nêu source.
6. **Không** gắn header vào skill CLI-wrapper viết tay trong `plugins/fgOS/skills/` (approve, cook, merge-loop, ...) — đó là source, không phải render. File không phải `.md` (`.agents/skills/distill/scripts/*.mjs`) ngoài phạm vi (ghi câu hỏi mở).
7. Sửa `docs/specs/distribution.md:63` row 4b: nguồn là `core/skills` + `domains/*/skills`, render bằng `npm run build:skills`, không sửa tay `.claude`/`.agents`/plugin copy. Xoá câu "edits `.claude/skills/fgos-*` and copies forward".
