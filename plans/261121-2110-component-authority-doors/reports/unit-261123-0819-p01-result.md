# Phase 1 result: crate and `fgos authority locate`

## Done

- New crate `fgos-component-authority` (`packages/component-authority/rust/`), added as a workspace member.
  - `model.rs` loads `layers.json`, `components.json`, `decision-kinds.json`, `contracts.json` and `doors/*.json`
    into typed rows with `deny_unknown_fields`; a missing file or directory is a distinct error. A door's id is its
    file slug. Tests: a valid model loads, an unknown field is refused, a missing file is refused.
  - `locate.rs`: `locate(model, sentence) -> Vec<Match>` with `{kind, id, canonical, matchedOn, score}`. Lowercase and
    Vietnamese diacritic folding (precomposed and combining), tokenising, canonical phrase hit > alias phrase hit >
    meaning-token overlap; ties by kind, then id. Tests: ranking order, diacritic folding, tie order, no match.
- Verb `fgos authority locate "<sentence>" [--json] [--limit N]`: `apps/fgos/src/wiring/authority.rs` (descriptor,
  projector, read-only provider), module listed in `wiring/mod.rs`, `NATIVE_SUBCOMMANDS` row in `routing.rs`,
  projector arm in `cli_projector.rs`, dependency in `apps/fgos/Cargo.toml`, `Cargo.lock` entries written by hand.
- Host contracts: `command-manifest.json` (help line and subcommand), `command-routes.json` and
  `command-route-annotations.json` (route `authority` -> `authority.locate`).
- `apps/fgos/tests/authority.rs`: runs the verb on the real model; `ghi file nguyên tử` and `atomic file write`
  both return `durable-file` first (matched on alias; grep of the model found no competing canonical or alias hit).
- `invocation_doors.rs` is unchanged: `authority` is an ordinary reader, and the lenient-root list must never grow.
