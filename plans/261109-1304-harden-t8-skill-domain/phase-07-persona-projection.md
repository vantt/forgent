# Phase 07 - Persona projection (T8-09, L-5)

## Context

Lead decision L-5: `scripts/project-agents.mjs` is **not dead**: it is the only producer of the four tracked generated agents `council-assumptions`, `council-feedback-loops`, `council-ship-maintain`, `fgos-placeholder` in `.claude/agents/` (each carries its "Generated by `scripts/project-agents.mjs`" line; the council agent types of the planning sessions come from them). It has no package script and no caller, so it runs by hand. Folding it into `build:skills` would start projecting the four marketing personas into tracked files (a behaviour change), so not now.

Arbitration T8-09 (red-team R-1): `scripts/project-agents.mjs:247-250` takes `name = def?.name ?? file.name` and writes `TARGET_DIR/${name}.md`, with the description spliced raw (`:113`). Today six tracked `.claude/agents/*.md` are AgentKit files with persona names (`code-reviewer`, `debugger`, `docs-manager`, `fullstack-developer`, `planner`, `researcher`; 16 tracked foreign, 4 generated), so one manual run with a persona carrying such a `name:` would overwrite them. The script is 258 lines; its domain walk (`:122`) moves in P11.

Reused doors: the loader's agent-name rule (`src/runner/agent-definitions.mjs`, the same file P11 edits one line of; read only here: find the exact rule by reading the loader and cite it), the generated stamp line the script already writes.

## Requirements

1. **Name = source file stem**, validated by the loader's name rule (cite `file:line`); a `name:` field that differs from the stem is refused by name.
2. **Newline in a scalar refused.** Any frontmatter scalar spliced into the output (`description` at `:113` and the other spliced fields) containing a newline or a `---` line is refused with the field and file named, before any write.
3. **Unstamped target skipped by name (lead decision after landing review: a refusal of the whole run left the four generated personas unregenerable).** If `TARGET_DIR/<name>.md` exists and does not carry the script's generated stamp (the "Generated by `scripts/project-agents.mjs`" line, anchored on its line, not `includes`), the script reports it by name, skips it, writes every other target (compute all, then write) and exits 1.
4. Output for the four existing personas is byte-identical (the test runs the script against the real `core/agents` in a scratch target and compares).
5. Budget ≤ 275 lines (from 258).
