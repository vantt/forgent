## Lessons

- A door row's allowed list from a census is a hypothesis: three of the census's allowed files matched nothing on this head, one matched only through a type name. Run the row first, then write the list from what matches.
- The test-region brace counter fails silently on a brace inside a string or char literal; a Rust file's later code can then be read as product. Worth a fix in `rust-source.mjs` by its owner.
- Moving a guard into a per-line pattern loses what needed the lexer's string shape or multi-line context; state the lost cases in the row instead of widening the pattern until it false-positives.
