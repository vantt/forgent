## Lessons

- A decision-history entry written from memory of the plan can state a wrong reason; the twin rationale was corrected against the phase files before commit.
- `check-decision-citation-drift` keys its baseline on line text: rewriting a baselined line needs the key updated, and `--write-baseline` run in a worktree is not safe.
- Retiring a CLI case whose claim is a declaration needs the vector row first; three verbs (`topic`, `doc`, `return`) had no row, so they were added before the cases went.
