# Measurement: Files rewritten by `npm run build:skills`

## Method

On a clean checkout of this repository, `npm run build:skills` (`scripts/build-skill-wrappers.mjs`) was executed twice in succession, and the files touched, modified, and managed were recorded.

## Measurement Results

`npm run build:skills` executes `renderSkillSurfaces`, which performs four sequential operations:
1. Assembles canonical skills from `core/skills/` and `domains/<domain>/skills/` into `.agents/skills/`.
2. Generates thin wrapper stubs under `.claude/skills/<name>/SKILL.md` redirecting to `.agents/skills/<name>/SKILL.md`.
3. Mirrors dev-skills (`fgos-*` and `_shared`) from `.agents/skills/` into `plugins/fgOS/skills/`.
4. Materializes instruction projections into `.fgos/instructions/effective/rules.json`, `.fgos/installation/projections/ledger.json`, and the managed block in `AGENTS.md`.

### Files and Directories Rewritten

1. **`.agents/skills/**`**
   - Assembled from canonical sources (`core/skills/**`, `domains/*/skills/**`).
   - Every file carries the generated stamp header: `<!-- Generated by fgOS skill assembly from ... -->`.
   - Classification: **Pure output** (safe to declare in `land.regenerate.files`).

2. **`.claude/skills/**`**
   - Generated thin wrappers containing frontmatter and redirection stubs.
   - Every file carries the wrapper stamp marker: `This is a generated thin wrapper (tsk-1qi) -- do not edit directly, edit the source instead.`.
   - Classification: **Pure output** (safe to declare in `land.regenerate.files`).

3. **`plugins/fgOS/skills/**`**
   - Mirrored copies of `fgos-*` dev-skills and `_shared/`.
   - All files carry the assembled stamp header.
   - Classification: **Pure output** (safe to declare in `land.regenerate.files`).

4. **`.fgos/instructions/effective/rules.json` & `.fgos/installation/projections/ledger.json`**
   - Pure output generated by `instruction-projections.mjs`.
   - Internal `.fgos/` projection metadata, managed under `.fgos/` lifecycle.

5. **`AGENTS.md`**
   - Contains repository foundations, governance, definition of done, and doctrine written by hand, with only a managed block between `<!-- fgos:instruction-projection:start -->` and `<!-- fgos:instruction-projection:end -->`.
   - Classification: **Hand-written with a generated block** (**NEVER declare in `land.regenerate.files`**).

## Recommendation for Phase 3 (`.fgos/config.yaml`)

Phase 3 should configure `land.regenerate` with:
- `run`: `"npm run build:skills"` (or equivalent command)
- `files`:
  - `".agents/skills/**"`
  - `".claude/skills/**"`
  - `"plugins/fgOS/skills/**"`
- `when`: including `"core/skills/**"`, `"domains/**"` (to trigger when skill sources change).
- Do **not** declare `AGENTS.md`.
