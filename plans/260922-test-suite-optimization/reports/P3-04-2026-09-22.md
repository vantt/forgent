# P3-04 Breaker quarantine ghi GitHub Actions variables

Status: PROPOSED
Summary: Đã cài đặt logic update breaker state qua `gh api`, xử lý lỗi fallback tạo issue vì `GITHUB_TOKEN` mặc định không thể ghi repo variables.
Concerns/Blockers:
- Vì `GITHUB_TOKEN` mặc định chỉ có scope `repo` mà không có admin access để PATCH variables, script sẽ tự động tạo một Issue yêu cầu người thật quarantine rule.
- Để tự động cập nhật được, cần cấu hình một secret chứa PAT (Personal Access Token) rồi truyền vào qua env `GH_TOKEN` trong job `compare` (không áp dụng hiện tại để tránh security risk).
