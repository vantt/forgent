## Deviations
1. Live check ran the hook in the head's sandbox from outside, not fired by a Claude head (the head CLI bound for tier standard is gemini, no hook rows for it; a Claude head would also stage a login inside its private home).
2. A stop that answers a pending rotation does not also measure (the role has not moved yet; a fresh successor is far below soft).
3. Without a request socket the hook asks nothing (an unconfined head has no `head rotate` caller here; the Node `requestRotation` stays for `fgos head rotate`).
4. No pending owner question source exists in any lineage state, so the hook never reports one (soft is never held by it; hard carries the last assistant message verbatim). No status-line sidecar writer ships, so the measure is the one-turn-stale transcript until one does. Both are in the contract.
5. Phase text asked for a doctor row; replaced by the existing row (above).
6. Incident: a first attempt to regenerate the hook rows with `doctor --fix` ran against the main checkout; the lead was told, every change was reverted (2 settings entries, one config comment line, one systemd timer). The golden vectors and settings were then produced by the Node door pointed at this worktree.

## Review round: every case of the deleted Node tests and its Rust owner
The sidecar poll keeps waiting for a file that does not exist yet (the first port stopped early), and a sidecar `ts` is epoch milliseconds or ISO-8601 as in Node (`parse_iso_millis`, through the civil-time door: RFC 3339 instants and dates; an offset-less datetime is no longer read). All in `packages/session-host/rust/src/rotation/`.

`measure.test.mjs` (5 cases):
- sidecar newer than Stop gives the fraction from its own window size: `measure::tests::a_sidecar_record_newer_than_the_stop_timestamp_gives_the_fraction_from_its_own_window_size`
- sidecar older than Stop is not fresh, stale transcript used: `...a_sidecar_record_older_than_the_stop_timestamp_is_not_fresh_and_the_stale_transcript_is_used`
- a record that lands while waiting (Node: the file did not exist yet): `...a_sidecar_file_created_while_waiting_is_taken` (plus `...a_record_that_lands_in_an_existing_sidecar_while_waiting_is_taken`)
- transcript sum, last non-sidechain entry, once per message id: `...the_transcript_sum_uses_the_last_non_sidechain_assistant_entry_once_per_message_id`
- no data at all measures nothing: `...no_data_at_all_measures_nothing`
- ISO-8601 timestamps (a Node behaviour with no Node test): `...a_timestamp_is_epoch_milliseconds_or_iso_8601_and_a_record_older_than_the_stop_is_not_fresh`

`decide.test.mjs` (8 cases, same config values): below soft, soft, hard (`below_soft_nothing_rotates`, `at_rest_between_soft_and_hard_rotates_soft_and_at_or_above_hard_rotates_hard`); pending question holds soft not hard (`a_pending_question_holds_soft_but_not_hard`); background task or cron (`a_running_background_task_or_cron_blocks_every_level`); unmeasured (`an_unmeasured_session_never_rotates`); persona override with soft and hard of `miu`, partial `half`, global `other` (`a_persona_override_replaces_the_global_thresholds_and_a_partial_one_keeps_the_other_global`); soft above hard refused by name (`soft_above_hard_is_refused_by_name_and_a_missing_key_is_not_defaulted`).

Wait rule (final): the 1500 ms wait applies only when the sidecar file already holds a record of this session (`writer_seen`, read from the real file: a writer has written for this session at least once). With no file, or only other sessions' records, the transcript is used at once (`no_writer_for_this_session_means_no_wait_and_the_transcript_is_used_at_once`). The two late-arrival tests run with an older record of the session present (`a_newer_record_that_replaces_the_file_while_waiting_is_taken`, `a_record_that_lands_in_an_existing_sidecar_while_waiting_is_taken`). Consequence: a head whose very first sidecar record has not landed yet is measured from the transcript once; no stall without a writer.
