## Steps

1. Remove `plans/backlog.md` from the `writes` of `supervisor` and `secretary`; keep `plans` and `plans/backlog/*`.
2. Update `permissions.rs` and `head-grants.test.mjs` to the new grant, and add (or extend the existing grant case

3. Secretary skill step 2: mint the id, write one row file `plans/backlog/<id>-<slug>.md` with

4. Specs: replace each sentence that names `plans/backlog.md` as a granted or session-written file with the
   settled fact: the index is generated by the land door on every land that commits a row, plan or discussion,
   and is never written by hand or granted.
