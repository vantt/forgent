# Phase 5 — Integration: combined gates, regenerated index, changelog

Capability: `code:test`. Depends on phases 1-4.

## Inputs

- `plan.md` of this directory (all acceptance criteria).
- The landed commits of phases 1-4 on main.
- `changelog.d/README.md` (fragment scheme).

## Footprint

changelog.d/261128-0105-backlog-index-generated.md, plans/backlog.md (written only by the land door),
plans/261128-0105-backlog-index-generated

## Steps

1. Write the changelog fragment:
   `- Changed: plans/backlog.md is generated by the land door from the row files, plans and discussions on every land that commits one of them; adding a row lands one file, and session write no longer accepts plans/backlog.md.`
2. On the combined tree (main after phases 1-4), run `npm test` and `cargo test --workspace`; save the summary
   to `reports/integration-gates.md`.
3. Land the fragment and this plan directory with `fgos land --paths`; the plan.md change is a feeding land, so the
   door regenerates `plans/backlog.md`. Check that the landed index equals the generator's output (criterion 7):
   a second land of the plan dir with no change leaves `plans/backlog.md` unchanged.
4. Live check of criterion 1: land one real new row through `fgos session write plans/backlog/<id>-<slug>.md`
   (or the next real row anyone adds) and record `git show --stat` of that commit in the report: one added file,
   `plans/backlog.md` modified.

## Verify

Both suites pass; the report records the stat of the row commit. Pass condition: criteria 1-7 each have
their evidence line in `reports/integration-gates.md`.

## Rollback

Revert the fragment; revert phases 1-4 per plan.md Risks and rollback.
