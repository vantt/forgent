## Verb contract and output

- `fgos git status [--json] [--dir]`, read-only. Keys: `repository {notARepository, commonDir, layout}`, `journal {initialized, complete, pendingCount, errors, retention{retainedChains, oldestRetainedAtMs, retainedBytes, ledgerCapacityWarning}}`, `pendingOperations [{operationId, kind, writer}]`, `retainedLand {candidates, complete}`, `worktrees {issues, pendingOperations}`, `nativeLocks`, `mergeInProgress` (sha or null). A part that fails answers `{ error: <cause> }` in place; only `git-addon-not-shipped` fails the whole verb. Not a repository: `{ repository: { notARepository: true } }`, exit 0 (checked in a scratch non-repo).
- `fgos git recover [--json] [--dir]`: `{ recovered: [ids], kept: [{operationId, cause, writer}], message }`, plus `mergeInProgress` and `next: "fgos main-checkout-reset --sha <sha> --confirm"` when a merge is stuck (never run). Never deletes worktrees, locks or refs.
- `fgos init`: last, fail-safe step; answer gains `gitRecovery {recovered, kept}` only when non-empty, `gitRecoveryWarning` on a refusal.
- Root resolution as doctor: `--dir` else `resolveMainCheckoutRoot(cwd) ?? cwd`.
