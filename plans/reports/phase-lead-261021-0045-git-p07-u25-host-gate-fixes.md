## Other branch failures

- **`git-fence-missing` (gate: 27 lines).** Fixtures built repos without the activation fence. Added `activateGitFixture` in `intake/discovery`, `intake/plan`, `claim-capacity-race`, `dispatch-production-call-sites`, `fanout-batch-runner-commit`, `loop-rununit`, `units-runner`, `custody-lease-commit`, the shared `workflow-fixture-repo` helper, and the one `setup/checks` test that creates a session.
- **umask 002.** Fixture state dirs were created group-writable and the Git driver refuses them. They are now created 0700 in `fences-rust-locks`, `fgctl-init-fixture`, `fgctl-init-preflight-tail` and `fgctl-upgrade`.
- **`custody-lease-commit`.** It called `commitUnitWork` without the now-required native baseline; it now captures it with `preflightUnitWorktree`, as the runner does. Its 64 MiB case then showed a product regression: the Git driver captured borrowed stderr (where hooks write) at 64 KiB, against holder-lock's "commit children request 64 MiB". Borrowed runs now capture up to 64 MiB; overflow still refuses, other Git children keep 64 KiB, and the WAL stores causes only. Spec G-062 has a dated note.
- **`claim-capacity-race`.** Its barrier was a `post-checkout` hook, but the Worktree port runs Git with an empty hooks dir. It now holds `worktree-admin` (the next test's barrier); the assertions are unchanged.
- **`driver-rununit:239`.** The branch moved the main-checkout policy check before the declared-operation check, so the wrong refusal won. The declared check now runs first; both still run before any Git port.
- **"--once should still exit 0 for a parked item", "git worktree add failed", most "strictly equal".** These came from R2 or the fence. What is still red here is confinement or herdr only.
