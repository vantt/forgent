## Headline

1. The agent protocol's `direct` half decides nothing in production. The supervisor calls only `adapter_for(..).activity_from(..)` and `newest_result` (`packages/run-supervisor/rust/src/supervise.rs:21,92,209,252`); `classify`, `Outcome`, `BlockedReason`, `StdinPolicy`, `ExitInfo`, `names_blocks` and six adapter files are exercised only by `tests/direct_vectors.rs` plus 387 lines of fixtures. Node settles direct runs from stderr through its own pattern list. Delete the dead half; keep one wording list.
2. Observe's `harness` scorecard has three sections that are constants or always zero (reproduced on this machine): `sessions` (no producer for source `coordination`/`workflow`), `complexity` (`total_routes = 50`, `native_routes = 2` are literals; protocols 0/0; it reads about 494 k lines of tracked files on every call), and `friction` (the string `"n/a (pre-F5)"`).
3. Observe has no shared door for its own stores: four hand-written "append a JSON line to the writer shard" paths, three "read all shards" paths, and 12 hand-rolled flag parsers that already disagree with each other.

## Part A. Target shape

### Agent protocol (`packages/agent-protocol/rust`)

- Authority: turning an agent CLI's screen (terminal mode) into a named outcome, and the one list of provider wordings (dead login, used-up quota). Direct mode keeps only what the supervisor consumes: "did the capture grow" and "newest `result-<N>.json`".
- Ports: `AgentIo` (send, screen, inspect, now_ms, pause), `Outbox`. Remove `AgentIo::read` and `AgentIo::activity`: no adapter calls them (`rg` in `src/` finds no `io.read()` / `.activity()` call) and the only production impl stubs them (`supervise/terminal.rs:482-488`).
- Per-CLI adapters: terminal side is already one table (`Profile` consts, 12-17 lines each, selected by `terminal/mod.rs:adapter_for`). Direct side is five identical structs; none of them needs to exist.
- Node budget after the move: `settle-attempt.mjs` loses its own limit word list (see D4); `provider-auth-failure.mjs` stays until T5 decides how dispatch settlement reads wordings (see M1). No Node file gains a rule.
- Size target: src 1 288 -> about 1 110; tests 684 -> about 620 (direct fixtures 387 JSON lines deleted).
- Doctor rows kept: none own. `agent-cli-project-trusted` stays as the machine-setup row (brief: not a code defect).

### Observe (`packages/observe/rust` and host wiring)

- Authority: friction store, case/eval journals, snapshots, scorecard sections that have a producer (`runs`, `tokens`, `faults`, `work`, `case`, `commits`), discussions, entropy. After the cut, one append door and one read door in `shard.rs`, one flag parser, one provider type.
- Rust/Node boundary: unchanged (Node reaches Observe through `invokeHost`); `src/observe/friction-client.mjs` shrinks to about 110 lines (F-N1).
- Doctor rows kept: `observe-dir-writable`, one merged host row (`observe-run-coverage` absorbing `observe-host-resolvable`), `observe-friction-migrated` until the fence is deleted (D17).
- Size target: Rust src 6 364 -> about 5 150 (before the fence deletion), tests 1 305 -> about 1 000. After the legacy friction fence goes: a further about 780 lines across crates (D17).
