- **Retired proofs, each with its owner** (design principle 8): missing file reads `{}` -> `facade.test.mjs` (standard); invalid JSON throws -> `config-door.test.mjs` (`config-parse`); command-list filtering -> schema refusal (crate golden); `describeConfigAwareness` -> removed with C13; "older release refuses a tombstone" -> `packages/config/rust/tests/files_select.rs` (a tombstone is no source), the old Node reader it stood in for is gone. `config-snapshot-hash`: the `$comment` assertion went because `stripConfigComments` was removed by the door change (a YAML comment never reaches a value); the uncovered-key assertion stays. `model-pool-checks`: three doctor branches cannot be reached once the standard is always the base layer (tier-fallback "not declared", tier-fallback "missing tier" warning, executor-skills "no declared skill"); each test now judges the standard's own answer or a project override of it.
- **`loadRunnerConfig(path)`, `DEFAULT_RUNNER_CONFIG`, `IRON_LAW_LEVELS`, `DEFAULT_IRON_LAW_LEVEL`, `DEFAULT_CAPABILITY_SLOTS`**: their test importers already import the owning modules (`src/runner/dispatch/config.mjs`, `src/setup/registrations.mjs`); nothing was left to move, nothing deleted (all have importers).

- **Real defects found by the flip, fixed in product code** (class d): `approve`, `return`, `plan`, `discover` read config at `path.dirname(.fgos)`, which in a session worktree is a `.fgos` symlink the door refuses (`config-path-symlink`); they now resolve the main checkout first (`bin/fgos.mjs`, 4 call sites). `fixGitDriverDirectories` read config through the door, which refuses while the very directories it repairs are unsafe; it no longer reads config (`src/setup/git-checks.mjs`). `fgos setup` probed the disk for `config.yaml` / legacy `config.json`; the crate's `init` now answers `{ created, file, revision }` (Rust `InitResult.file`, addon, facade doc, crate golden, `config-door` test) and `bin/fgos.mjs` builds the path from it, so the facade is the only reader.
- Tests that launched real agents: every fixture whose unconfigured capability fell through to a standard executor started a real herdr pane (`HERDR_ENV=1`); all are fixed; one stray pane (`w4:p6C`) left by my first sweep was closed.
