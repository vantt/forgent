# Implementation report: identity machine and session handles (phases 01-02)

Branch `ident/p01-p02-machine-session-handles` (base main 755ad3035). Not pushed, not merged.

## Status
Both phases implemented in one code commit (the two share provider.rs, resolve.rs, lib.rs, projector, registry and contracts; a clean split was not worth a broken intermediate), plus a drift-guard commit and this report.

## What changed
- `fgos-identity` (packages/identity/rust): new `text` (random_hex128, slug, base32_prefix), `machine` (valid_machine_id, read, mint, alias, handle), `errors`, `session` (pure rules: CLI part, 4-char suffix, pid local id from boot id + pid + start time, full id, handle). Host provider behind default feature `provider` (host-runtime, holder-lock, convention, process). Event Store depends with `default-features = false` (verified: `cargo tree -p fgos-event-store` has no fgos-host-runtime).
- Event Store: `valid_machine_id`, mint and slug moved down; `machine_id(config, state_root)` kept as ref-name rule with its own error codes; `random_id` and `branch_key` call the identity text module; duplicate validity cases and `setup_identity.rs` deleted (owner: `identity/rust/tests/machine.rs`).
- Operations `identity.writer` (outcome 1.1.0, bare, Read/Safe), `identity.read`, `identity.write`; subcommands `writer|machine|session`; `machine --alias` is the only write. Refusals exit 65 with reason (`machine-id-missing`, `unresolved`, `invalid-alias`...) through a typed `Refusal` outcome the presenter prints.
- Convention kinds `machine-handle` (max 40), `session-suffix` (a-z2-7, max 4) with golden cases.
- Doctor `identity-machine-id` (warn when absent, fail when unreadable) and fix (mints through the existing N-API; `fixEventStoreMachineId` unchanged and still the one mint door). Contracts: identity.read/write v1, writer gets optional `machine`/`session`.
- Docs: identity spec (sections 3, 4, 5, 7a), event-store spec, component-boundary, distribution row 7, setup-doctor-registry, architecture manifest row, CHANGELOG.
- Not touched: proc_tree.rs, node-addon Cargo.toml/lib.rs, src/util/session-identity.mjs. `env_var` added to `WriterIdentity` (serde-skipped).
- Deviation: the manifest test requires `sub` required and examples under `fgos identity <sub>`, so the registry documents bare as `writer` (bare still works as before). Alias read from a hand-edited invalid file falls back to the derived handle.
