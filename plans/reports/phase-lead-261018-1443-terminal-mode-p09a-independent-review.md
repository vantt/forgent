# Independent review: terminal-mode/p09a-integration (one round)

Method: read-only (grep + file reads). No cargo/npm run. Verdicts are from code reading, not execution.

## Ranked findings

### MEDIUM
- M1 (UNSURE) supervise/terminal.rs:602-605 wait loop `while !sup.gate_gone { tick; sleep }` has no bound. `gate_gone` flips only when `domain_is_empty == Empty` (terminal.rs:364). tick's escalation (`domain_kill_all`) runs once (`ended_domain`, :415-418), never repeated. A domain that reports Unknown/NotEmpty forever (unkillable/D-state proc, unreadable /proc) hangs the supervisor and holds attempt lock + cwd lease indefinitely. Direct mode has a bounded kill_all+is_empty path (supervise.rs:~362). Fix: retry kill_all every N ticks, cap with a deadline, then release lease with receipt noting `domain-not-empty`.
- M2 (UNSURE) terminal.rs:566-577: after `core.launch` succeeded, `gate_tuple` / `bind_record` / GO-send failures `return Err(Refusal::internal)` without `finish()`: no receipt, no release-slot, no cleanup-trust step from the supervisor. Controller does not abandon either (`attemptHandedOver=true`, assignment-runner.mjs:2464, :2645). Recovery depends on adopt (assignment-runner.mjs:~2476 `adoptRun`). Verify adopt runs release-slot (Retain) + cleanup-trust when receipt is absent in terminal mode; otherwise pane + trust entry leak. Also `domain_kill_all` result ignored (terminal.rs:569,575) and `locks` dropped on Err, so lease can release before emptiness is proven (low risk: no GO sent yet, no agent exists).

### LOW
- L1 gate_tuple fallback (terminal.rs:251-252): a peer pid that is non-zero and NOT within the pane tree is not rejected; falls through to `namespace_init_under` and GO (with lock fds via SCM_RIGHTS) goes to that connection. Auth is uid+HELLO(attemptId) as designed (same-uid can ptrace anyway), so not a trust-boundary break, but cheap hardening: reject when `peer pid != 0 && !within`. Also accept loop is serial with 5s read timeout per stranger (terminal.rs:129): same-uid stranger can burn HELLO_LIMIT. Same-uid only.
- L2 confirm_submitted working branch (mod.rs:~419-430): when `draft_still_in_composer` is true while working (short/file-pointer brief echoed in bottom 6 lines; claude OSC title in `prompt_text` e.g. fixtures claude/working.insp.json holds `◐ Single word reply`, so a brief shorter than 48 squashed chars matches `holds(boxed)`), Delivered is delayed by SUBMIT_WORKING_MS=8s, not lost. Latency cost only; Delivered stays reachable as long as `working` is continuous.
- L3 idle branch now reads the screen whenever idle (mod.rs:~436-441), so chip/window checks on `bottom` now also apply when `prompt_text` is non-empty (before: only when empty). Risk: idle + transcript echo in bottom 6 lines (`[Pasted text #N +M lines]` echo in claude history, or >=2 brief-verbatim lines of >=30 chars, `holds_a_window`) = false "draft" => Enter pressed up to SUBMIT_MAX_ENTERS=6 on an empty composer (no-op in all five TUIs as far as fixtures show) then DeliveryUnknown after exhausting. Pre-existing shape for empty prompt_text; widened now. No fixture-backed case found for pi/omp/claude/agy that yields this (bottom 6 non-empty lines are mostly footer/separators), but no pi `working`/post-submit fixture exists, so pi/omp coverage is by inference.
- L4 disposition_for (terminal_slot.rs): `reason` non-null (e.g. `terminal:completed-no-exit`) forces Retain even when result was delivered; pane kept 24h. Conservative, intended probably; just noting.

### INFO
- I1 launch_line no longer `exec` (core.rs:702-710) + `match_expected` no pid exclusion (identity.rs:~29): shell never carries launcher argv so matching is safe (test `a_pane_still_on_its_own_shell_matches_nothing`). Side effects: root identity is now the child (bwrap/gate), shell stays parent. gate_tuple `within(pid, root.pid)` still holds. `give_back_foreground` (unix.rs:496) now returns tty to the shell-assigned job group, correct. No regression found. Shell syntax `cd 'x' && 'cmd'` fine in sh/bash/zsh/fish>=3.
- I2 ready_gate re-inspect (mod.rs:240-248): only changes outcome when blocker appears after settle; `Err` ignored. Falls to `blocked_readiness` which yields NeedsHuman when screen classifier knows no reason (safe-stop, not Ready). Codex marker `trust this folder?` added (codex.rs). No regression path found for pi/omp/claude/agy (they could previously also return Blocked at await_ready loop top for same flags).

## Checklist verdicts

1. Peer auth uid-only: OK. Gate side: file owner + `SO_PEERCRED` uid == euid, pids never compared (unix.rs:119-135). Supervisor side: `peer_uid == me` + HELLO attemptId (terminal.rs:131). Socket dir 0700 owner-checked, socket 0600 (:101-113). Caveat: pid from SO_PEERCRED is used as identity hint with `within()` filter (terminal.rs:251) = see L1 (not trust, but unrejected stranger pid).
2. SCM_RIGHTS CLOEXEC: OK. `MSG_CMSG_CLOEXEC` (unix.rs:255-256, Linux) + `set_cloexec` on every received fd (:279-281; non-Linux race window closed by single-threaded gate). Inherited `--lock-fd`/go fd CLOEXEC before anything (:29-39). `UnixStream::connect` is SOCK_CLOEXEC; signal pipe CLOEXEC (:196). Agent spawn passes empty fd map `spawn_with_fds(cmd,&[])` (:593). Late descriptors in `drain` closed unread (:351-353). MSG_CTRUNC rejected (:282). Locks only dropped after supervise_agent (:109).
3. Env scrub: OK. `env_clear().envs(config.env).envs(secrets)` (unix.rs:523); terminal mode re-adds only TERM/COLORTERM/TERM_PROGRAM/TERM_PROGRAM_VERSION and `HERDR_*` from the gate's own (pane) env (:511-534); FGOS_SESSION_ID / FGOS_PARENT_WRITER_ID from envelope identity, parent env_removed when absent (:535-541); terminal envelope without identity.writerId rejected (gate.rs:222). Node side strips CLAUDE_CODE_SESSION_ID/CODEX_THREAD_ID/FGOS_SESSION_ID in `workerBaseEnv` (adapters.mjs:114-126) and pane vars via `withoutPaneEnv` (herdr-round.mjs:52, assignment-runner.mjs:~2443). Test `gate_terminal_socket.rs:142-153` asserts both; note it early-returns when bwrap unavailable (:133) so the pane-env test is skipped without bwrap. Pane `HERDR_*` is passed to agent by design.
4. Node controller decides nothing: OK. Grep of all nine deleted names in `src/` = 0 hits. herdr-round.mjs (493 lines) = prepareTerminalAttempt (brief, confinement, allocate pane, trust seed), `abandon()` (pre-handover only: assignment-runner.mjs:2645 guarded by `!attemptHandedOver`), `followPaneScreen` (display only, errors swallowed). Only close it can do is of a pane the agent never saw. OK.
5. terminal.rs races/leaks: mostly OK, see M1/M2. Socket: `socket.close()` after accept (:564) and on silent gate (:561); `Drop` covers every other return incl. `?`. Accepted `stream` moved into `Sup.go`, dropped with `sup` (:614) or on Err returns. Release-slot disposition: Close only if receipt outcome=exited && outboxPresent && no reason && all earlier steps done, else Retain; skipped while a step retries (steps.rs:75-86, terminal_slot.rs disposition_for); unit-tested for the six non-clean outcomes. OK.
