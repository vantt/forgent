## Findings that change phase 6

1. Parser selection by adapter string is wrong in practice: openai runs produced pi JSON (op_004) and codex stderr (op_002) under the same executor. Select by invocation command from the resolved plan (`dispatch-plan.json` `invocation`/executor, see `command` in `core/config-standard/runner.yaml`), falling back to stream shape.
2. Live data: of 98 runs only the pi/omp headless streams carry real usage; claude (8) and agy/gemini (14) yield nothing from stdout/stderr today. Of the pi/omp streams, several carry only zero-usage turns.
3. Claude is the only provider whose counts are reliably recoverable after the fact, from the transcript, for both headless and pane. Phase 10's transcript source and phase 6 should share one field map; do not add `--output-format json` to the headless args (it would break the prompt-stdout protocol) unless phase 6 decides to.
4. Cache semantics differ: claude `input_tokens` excludes cache; pi/omp `input` also excludes cacheRead/cacheWrite (op_004: 317 + 30592 = 30909, total 30914 with output 5). Phase 6 must store them as separate measures and never derive input from total.
5. Cost fields exist for claude (`total_cost_usd`, `costBasis:"list"`) and pi/omp (`cost.total`); none for codex or agy. Record as `cost_usd` with basis `reported`; absent means absent.
6. Reason vocabulary the parser can return when counts are absent: `transcript-not-found`, `no-structured-output`, `no-assistant-turns`, `footer-missing`, `no-count-in-screen`, `agy-exposes-no-counts`, `unsupported-cli`, plus `reported-zero` (counts present, all zero). Each CLI row above names its own.

## Limits

- `codex`, `pi`, `gemini` binaries are not on this host's PATH, so no version string and no fresh run for them; their samples are from live logs and the current parser's documented shape.
- Pane samples are screen dumps; no pane run in the sample set exposes counts.
- Transcript shape for claude was confirmed from the one `usage` line of a throwaway session file; pi/omp session-dir contents were not inspected.
