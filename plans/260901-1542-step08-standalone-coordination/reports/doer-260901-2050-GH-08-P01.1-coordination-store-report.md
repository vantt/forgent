# Doer Report — P01.1: CoordinationSession store, schema, events, direct cutover

Track: `step-08-standalone-coordination` · Phase 01 R1-R4 · Branch:
`step-08-standalone-coordination`

## Summary

Implemented `src/runner/coordination/{schema,store,replay}.mjs` — a
versioned, fail-closed CoordinationSession manifest/event store exactly
matching `docs/architect/agent-coordination/contracts/coordination-session.md`
— and directly cut over `mission-lite.mjs` to it. Store/schema/events/
cutover only; no session engine, dynamic consult, or live proof (P01.2's
scope). 750-test focused suite green; full suite (4720 tests) shows only a
strict subset of the pre-existing 11-item baseline failure list, no new
failure.

## Files Created

- `src/runner/coordination/schema.mjs` — pure validator for the manifest
  and event-log shape (`validateManifest`, `validateEventPayload`,
  `applyAggregateBoundDefaults`, `assertAssignmentIsSessionBlind`,
  `assertNoForbiddenFieldsDeep`, `CoordinationError`). No fs, no imports
  beyond nothing (zero-dep pure module).
- `src/runner/coordination/store.mjs` — `openSession`, `bindActor`,
  `createSessionAssignment`, `linkResult`, `transitionSessionStatus`,
  `readManifest`, `readSessionEvents`. Reuses `state/events.mjs`'s
  `withEventsLock`/`appendEventLocked`/`readEvents` for every write and as
  the critical section that makes the atomic-ref rule atomic; reuses
  `dispatch/assignment.mjs`'s `buildAssignment()`/`claimAssignmentId()` for
  every Assignment created — no parallel Assignment-construction path.
- `src/runner/coordination/replay.mjs` — `replaySession`: reconstructs a
  session's state from `events.jsonl` + `session.json`, fails closed
  (`CoordinationError` with a named category) on schemaVersion mismatch,
  corrupt log line (bubbles `EventLogError('corrupt-log')` from
  `state/events.mjs` unchanged), duplicate `assignment-created`, dangling
  ref in either direction, foreign ref, out-of-order `result-linked`, and a
  tampered Assignment carrying a forbidden session/coordination field.
- `test/runner/coordination-schema.test.mjs` (34 tests)
- `test/runner/coordination-store.test.mjs` (18 tests, incl. two real
  `worker_threads`-based concurrent races)
- `test/runner/coordination-replay.test.mjs` (11 tests, one per corruption
  category)
- `test/runner/coordination-static.test.mjs` (2 tests: import-graph static
  negative)
