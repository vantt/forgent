the SAME `partialPolicy`-can-only-be-declared-at-open gap filed as `tsk-40j`

`requiredActorIds` from the protocol's full 4-actor roster regardless of
what a request's own `actors[]` declares — so a review-only follow-up
session can never omit an actor it never intended to use unless that actor
is named in `partialPolicy.allowedOmissions` from that SAME session's own
first request. The Lead's disposition below rests on the real, independently
verified review + red-team evidence gathered across these sessions, not on
any one session's own `closed` status — matching the Group-Thinking
Execution Contract's real gate (point 7: "clean or deferred with rationale"),
which is a Lead judgment call, never itself gated by session bookkeeping.
