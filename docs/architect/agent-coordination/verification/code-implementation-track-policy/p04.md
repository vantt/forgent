## Review findings and fixes (commit `63b01fa9`)

A real review of P03's shipped `fgos-code-panel` policy (`domains/coding/skills/fgos-code-panel/SKILL.md`) found four issues, all fixed in this one commit:

1. **HIGH — close only ever certified the cell's own worktree tip, never the merge commit.** If `$base` moved during the cell's lifetime (a clean, conflict-free `--no-ff` merge still unions in every commit `$base` gained meanwhile) or the merge needed conflict resolution, the merged result could ship without ever being tested. Fixed by adding a required post-merge tree-identity check between `git merge` and worktree/branch removal (SKILL.md "Post-merge verification" section, current lines ~531-559): compare `mergedTree` (`git -C "$main" rev-parse HEAD^{tree}`) against `testedTree` (`git -C "$wt" rev-parse <cell-branch>^{tree}`) under an unchanged environment fingerprint. Identical → the close's proof already certifies the merge commit, record `treeIdentical: true` with both shas, no re-run. Not identical → run `AFFECTED_TESTS` against the real merged diff at minimum, escalating to `FULL_TEST` on a `FULL_TRIGGERS` hit recomputed against that merged diff (not just the cell's own diff, since `$base`'s own new commits can trigger it too).
2. **MEDIUM — "every cell trace" had no defined storage location.** Fixed by explicitly naming the coordination session's own event log / `close.json` disposition `rationale` as that record (queryable via `fgos coordination show code-panel--<change-slug> --json`), not a new `docs/`-tree directory keyed by "code-panel" — the user explicitly rejected a proposed `docs/architect/agent-coordination/verification/code-panel/<change-slug>.md` path during this review as inconsistent with the skill's own "no index, no track directory" Non-Goals (SKILL.md "Record it" section, current lines ~227-249).
3. **MEDIUM — P03's own trace only said "167/167 pass," no exact command/duration/fingerprint.** `p03.md`'s "Targeted tests" section did not satisfy the exact-command/duration/fingerprint evidence contract the "Record it" section itself requires.
