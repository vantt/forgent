## Full-suite regression sweep

`npm test` on the merged tip: **6384 tests, 6335 pass, 41 fail** (real exit code captured directly, not through a exit-code-hiding pipe). All 41 failures independently triaged and confirmed pre-existing/environmental, none caused by this track:

- **~24 `test/rust-host/*.test.mjs` failures** (fgctl-init, fgctl-upgrade, release-tree): gated by a `before` hook requiring a pre-compiled `target/release/fgctl`/`fgos` Rust binary (`cargo build --release --workspace` was not run in the verification worktree) — a separate, unrelated Rust-host track's own environmental setup gap, not a code defect.
- **`đủ sổ` (architecture-manifest completeness)**: a broad, pre-existing gap spanning 75+ files across the whole repo, unrelated to this track. This track's OWN 4 missing rows (`cli-spawn-supervisor.mjs`, `read-evaluators.mjs`, coordination `recovery-planner.mjs`, coordination `recover.mjs`) were fixed as part of this closeout (see below) — the remaining gap belongs to other areas of the codebase, out of this track's scope.
- **`buildCandidateInventory against the real committed .fgos/config.json`**: confirmed via `git log -- .fgos/config.json` that no runtime-recovery commit ever touched this file; its current content diverges from this test's expectation for reasons entirely unrelated to this track.
- **`coordination-research-fan-out` R5 concurrency**: the same pre-existing flake documented and independently reproduced on `main` across P02H, P03, P05 and P05S's own trace docs.

Fixed both the production usage/error text and the test's own regex expectations; 41/41 in that file's suite.
