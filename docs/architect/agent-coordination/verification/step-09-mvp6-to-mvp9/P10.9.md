## 8. Design Notes — judgment calls made, and why

- **No new crash-recovery test authored for `runGroupThinkingRequest`
  specifically** (Property #3). Reasoned explicitly in §1 row 3: the pack
  gate carries no independent persisted state — every call re-reads fresh
  and forwards unchanged into the same event-sourced door every existing
  crash-recovery test already exercises, and P10.5's own sequential
  open-then-resume test already demonstrates the exact shape a "crash
  between calls, then resume" would take at this layer. Writing a second,
  structurally identical test under a different name would not close a
  gap this reasoning doesn't already close (YAGNI) — named as a considered
  judgment call, not an oversight, matching current-cell.md's own explicit
  invitation to make this call and document it either way.
- **The new R7 extension walks the whole `src/verbs/coordination/**`
  directory, not just `group-thinking-pack.mjs`.** Matches this repo's own
  established precedent (R7's original scan, P09.3's extension) of a
  dynamic directory walk over a hardcoded file list — any future file
  added to that directory (a new public-surface verb, a future protocol
  pack sibling) is covered automatically, with zero required changes to
  this test. Confirmed the walk currently also covers `run.mjs`, `show.mjs`,
  `launch-master-loop.mjs`, and the public-surface `schema.mjs` — all
  already clean (0 violations, 3 non-trivial real exports minimum
  sanity-checked via `totalExports > 5`).
- **`core/skills/fgos-group-thinking/SKILL.md` was read, not scanned.**
  current-cell.md's own gap-check text names this path alongside
  `group-thinking-pack.mjs`. It is prose (a Markdown skill file), not a
  module with exported functions — the export-name-scan mechanism this
  cell's Property #8 fix uses does not apply to it. Read in full instead
  (quoted in §1 row 2's reasoning): it names no CLI verb, no direct
  session-store access, and explicitly documents (its own "The gate, and
  why it holds" section) the same five-bypass reasoning P10.1.md §5
  already proved structurally — no separate check was warranted for a
  file that adds no callable surface of its own.
