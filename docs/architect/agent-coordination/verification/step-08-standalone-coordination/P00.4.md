### Findings

**MEDIUM — `assignment-policy.mjs`'s fix does not mirror `resolve.mjs`'s
extraction for a bare (non-`invocations[]`) executor entry with a real
non-Claude command; the two call sites still disagree for that shape.**

Violated requirement: P00.4.md's own Acceptance line ("mirroring

no live dispatch is mis-tagged today — but silently reproduces the exact

this is not a one-line tweak — a naive full-parity fix (also reading
`registeredExecutorEntry?.command` for the bare-shape case) was already

check or `validateExecutorShape`-time warning) that fires if a future
bare-shape executor is ever registered with a non-Claude-CLI `.command`
and no `providerModel`/`provider` — at minimum this residual gap should be
written into P00.4.md's Gaps section, which currently doesn't mention it
at all.
