## Deferred (not blocking — 3-round fix cap reached; 0 HIGH remaining, all confirmed non-regressing)

- **M-1** (MEDIUM): `CHANGELOG.md`'s R7 bullet still claims all 7 canonical capabilities (`advise`, `execute`, `code:implement`, `code:review`, `code:test`, `code:debug`, `code:refactor`) got an explicit `unconfined` declaration. A precise one-line correction, specified exactly in the fixer briefs of both failed attempts — never landed because both attempts timed out before writing anything.
- **M-2** (MEDIUM): `test/runner/dispatch-production-call-sites.test.mjs`'s fixture is not isolated from the operator's real global `~/.fgos/config.json` — `loadRunnerConfigFromDir`'s `mergeWithGlobalConfig` (config.mjs:255-272) leaks it in, causing 2 stable test failures on this machine's current config. Per op_062's own I-1, this has two independent halves: isolating the fixture's runner-config resolution from `HOME`, AND (found the hard way) the bwrap backend registry *also* reads from `HOME`, so a naive blanket `HOME` override breaks 3 other confinement tests — both halves need to move together. This is a test-isolation quality gap, not a live production security gap (production dispatch itself behaves correctly; only the test's own environmental independence is broken) — deliberately left out of scope for the narrowed round 3c attempt to preserve time budget for M-3, and never reached by either fixer attempt regardless.
- **M-3** (MEDIUM, real production no-overclaim gap, reachable today): `buildConfinementRequest`'s anchor-inheritance (request.mjs:141-144) copies an anchor capability's confinement wholesale, including when the anchor's own mode is `unconfined` with no `omitted` flag — so a capability that declared nothing inherits a durable "explicit opt-out" attestation (`outcome:'unconfined'`, evidence kind `explicit-opt-out`) indistinguishable from a capability that directly declared `unconfined` for itself. `authority.mjs`'s explicit-vs-unknown decision (~line 85) keys solely on `(mode==='unconfined' && !requirement.omitted)`. REQUIRED/PREFERRED-mode anchor inheritance is unaffected and correct (op_062/op_064's own live probes, cases D/E). Live-probed twice (op_062, op_064) with fixed dispatchIds for byte-for-byte comparability; the fix itself (mark the inherited requirement with `omitted:true` or a distinct `inheritedFrom` marker, and have `authority.mjs` check it) was specified precisely in both narrowed-scope fixer briefs but never landed because both timed out before writing anything.
- **Executor-timeout infra finding** (see "New structural finding" above): `codex-herdr` burned its full 35-minute ceiling twice in a row with zero commits, on two different task scopes (one large/combined, one deliberately small). Whoever picks up M-1/M-2/M-3 next should either swap the fixer executor away from `codex-herdr` for this specific task, or raise the per-dispatch wall-time ceiling, rather than retrying the same executor a third time on an even smaller slice.
