## 1. Reading Rule

Read [vision.md](vision.md) first, then this ledger before narrowing, staging, or simplifying host invocation. This ledger does not create architecture by itself. It preserves original intent, source disposition, and proof gaps so old detail is not lost while target docs are promoted.

| Status | Meaning |
