**Structural findings for a future Lead, distinct from prior cells:**
1. **`agy-herdr` can fail its own herdr handshake not just at initial dispatch (P03's finding) but also mid-task during a re-brief.** Same remedy applies: swap the executor rather than retry the same one. `claude-reviewer-herdr` proved reliable as a fixer substitute across 2 consecutive rounds in this cell after the swap.
2. **A `coordinationId`'s `aggregateBounds.wallTimeMs` is measured from session OPEN time, not from the start of the current round** — a cell that survives a mid-flight CLI death, a failed fix round, and multiple recovery dispatches can burn its entire 2-hour budget on overhead before ever reaching its final recheck, even though each individual dispatch was well within its own `timeoutMs`. When this happens, open a fresh `coordinationId` scoped to just the remaining steps (with `partialPolicy` naming the roles that don't need to run again), the same recovery already established for poisoned authorization slots.
