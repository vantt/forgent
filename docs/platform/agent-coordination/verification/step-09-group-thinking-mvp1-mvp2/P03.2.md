The fixture's header paragraph explaining "there is no `activation` field
yet to mark a binding `driver-authorized` versus `required`" was replaced,

other change: same six operations, same four actors, same four graph
nodes, same entry, same transitions, no topology, `metadata.version`
deliberately left at `1.0.0` (see the version note in Gaps).

**Why it was required, not cosmetic.** `authorizeDeclaredOperation`
refuses any binding whose activation mode is not `driver-authorized`

`operation-authorized` event could ever exist for this fixture, and R5's
"authorized revision, authorized recheck" plus R6's "unauthorized optional
operation refused through the CLI door" were both unreachable. Mutation
M6 below is the proof this is load-bearing rather than decorative:
removing `activation` from just the `reviewer-recheck` binding drops the
suite to 20/23, failing the fixture-shape test and BOTH full live-proof
runs.
