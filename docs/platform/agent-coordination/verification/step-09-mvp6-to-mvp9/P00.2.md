## 2. Team Cognition Module Boundary Decision

**Decision: does not exist yet — propose minimal new boundary, no existing
authority moved.**

Verified by two independent checks against live `src/` (not docs):

1. `grep -rliE "team.?cognition|aggregation-validated|cognitive" src/ core/`
   returns exactly one hit, `src/state/work.mjs`, and that hit is a false
   positive — a comment describing `work.tier` as "the cost/cognitive
   weight" of a work item, unrelated to Team Cognition
   (`src/state/work.mjs:153`).
2. `grep -rn "visibilityWindows\|specialistSlots\|deliberation-contribution\|aggregation-validated\|evidence-preserving-synthesis" src/ core/ docs/architect/agent-coordination/contracts/`
   returns zero matches anywhere in source or the two accepted contracts —
   confirming these MVP6-9 candidate fields are not implemented or
   contract-referenced today, consistent with `flow-definition.md` and
   `coordination-session.md`'s own "Implementation" headers, which list
   only MVP1/MVP2 (`activation`, `operation-authorized`,
   `driver-disposition-recorded`) as implemented.
3. `find src -maxdepth 2 -type d` lists only `src/runner/coordination`,
   `src/runner/definitions`, `src/runner/dispatch`,
   `src/runner/prompt-templates` under `src/runner/`; no `team-cognition`
   or similarly named directory exists anywhere under `src/`.

**Proposed minimal new boundary** (path only — P07.1 to create, not this
cell): `src/runner/team-cognition/`, sibling to `src/runner/coordination/`
and `src/runner/definitions/`, matching this repo's existing flat
`src/runner/<concern>/` convention rather than the draft `packages/`
overlay in `component-authority-boundary-map.md` §14 (that overlay is
explicitly "a proposal... existing files stay where they are until a later
slice creates a facade" — §14, and is not itself accepted). Suggested
initial files, not prescriptive beyond naming the boundary:
`src/runner/team-cognition/schema.mjs` (aggregation/contribution enums,
`AggregationError`), `src/runner/team-cognition/aggregation-evaluator.mjs`
(the P07.1 evaluator itself). Corresponding tests:
`test/runner/team-cognition-*.test.mjs`, matching the existing
`test/runner/coordination-*.test.mjs` naming convention.

This satisfies `component-authority-boundary-map.md` §6's authority row for
Team Cognition Engine ("Typed deliberation interpretation, aggregation-method
semantics... Must not own: CoordinationSession terminal transitions,
context-grant authority, Assignment dispatch...") without moving any file
currently owned by `session-runtime` or `definition-schema`.
