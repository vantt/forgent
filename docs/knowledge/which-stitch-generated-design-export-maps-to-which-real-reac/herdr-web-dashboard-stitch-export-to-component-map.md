# Herdr web dashboard: stitch export to component map

The herdr web dashboard's visual design was generated by `stitch` (a
Monday.com/ClickUp-style theme) and applied into the real React
components under `herdr-plugin/web/src/`. This is the map between the
generated export and the component it styles.

| Stitch export | Real component | Covers |
|---|---|---|
| `herdr-plugin/web/stitch-exports/S01/` | `App.tsx` | Sign-in screen |
| `herdr-plugin/web/stitch-exports/S02/` | `Taskboard.tsx` | Group view (status-grouped columns, the default) |
| `herdr-plugin/web/stitch-exports/S02-kanban/` | `Taskboard.tsx` | Kanban view — a second board view of the same grouped data, toggled next to Group-by in Controls (`D16`, `docs/history/herdr-web-dashboard/CONTEXT.md`); desktop-only, mobile always shows group view |
| `herdr-plugin/web/stitch-exports/S03/` | `TaskDetail.tsx` | Expanded item context: `description`, `verify`, `footprint`, `docsRef` (`D17`, same CONTEXT.md — the real `WorkItem` fields beyond id/title/status the earlier spec had missed) |
| `herdr-plugin/web/stitch-exports/S04/` | `NeedsAnswer.tsx` | Needs-answer screen |

`D16` and `D17`'s own design rationale (why a second board view, why those
specific fields and not `kind`) is locked in `docs/history/
herdr-web-dashboard/CONTEXT.md` — this table only records where each
design landed in code, not why it was designed that way.
